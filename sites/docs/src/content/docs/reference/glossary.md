title: Words used here
description: What each noun in Kolibri means, in one line, with a link to the page about it.
sidebar:
  order: 4
---

| | |
|---|---|
| **Activity trail** | The record of every change to a task, with who made it. Cannot be written to — see [the task itself](/tasks/detail/#the-activity-trail) |
| **Baseline** | A saved snapshot of a plan's dates, drawn behind the live one — see [the timeline](/planning/timeline/#baselines) |
| **Board** | The Kanban layout. Columns are whatever you grouped by — see [the five layouts](/views/) |
| **Burn-up** | Two lines over a cycle: everything in it, and everything finished — see [insights](/planning/insights/) |
| **Container project** | A project that holds only other projects and has no board of its own — see [across projects](/planning/portfolio/#projects-inside-projects) |
| **Custom field** | A question asked of every task in a project. Nine kinds — see [custom fields](/tasks/custom-fields/) |
| **Cycle** | A fixed window of time with tasks in it. A sprint — see [cycles](/planning/cycles/) |
| **Direct conversation** | A chat between exactly two people, identified by the two people rather than by an id — see [chat](/people/chat/) |
| **Estimate** | A guess at size, in points. Never compared with logged time — see [the task itself](/tasks/detail/#estimates-are-points-on-purpose) |
| **Group** | One of the five buckets every workflow state belongs to: backlog, todo, in progress, done, cancelled. What the app reasons about when your columns have their own names |
| **Guest** | A role that sees only the projects it has been added to — see [members and roles](/people/members/) |
| **Identifier** | `WEB-42`. The project key plus a number that is never reused |
| **Intake** | A public form whose submissions wait in a queue — see [intake forms](/people/intake/) |
| **Key** | Two to five letters that prefix every task in a project |
| **Label** | A project's own vocabulary. A task wears any number |
| **Module** | A milestone that may span several cycles — see [modules](/planning/modules/) |
| **MCP** | Model Context Protocol. How an assistant talks to Kolibri — see [connecting an assistant](/beyond/assistant/) |
| **Outbox** | The queue of changes made on your device that have not reached the server yet — see [working offline](/beyond/offline/) |
| **Page** | A markdown wiki document, nested to any depth — see [pages](/pages/) |
| **Relation** | A link between two tasks: blocks, is blocked by, relates to, duplicates |
| **Rule** | A watcher that files a template when something happens — see [rules](/automation/rules/) |
| **Saved view** | A named layout, grouping, filter and sort — see [saved views](/views/saved/) |
| **State** | A column in a project's workflow. Its name is yours; its group is one of five |
| **Sub-task** | A whole task with a parent. Not a checklist item |
| **Template** | A task written in advance, with a checklist that becomes sub-tasks — see [task templates](/automation/templates/) |
| **Tombstone** | What a delete actually writes. It syncs, and *Settings → Data* undoes it |
| **Team** | A group of people who own projects, and a recipient a rule can address |
| **WIP limit** | A number on a board column that colours its header when exceeded. It never refuses a drop |
| **Workspace** | The outer container. Nothing references across two of them |
